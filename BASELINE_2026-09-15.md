## Baseline scope
- Next.js 16.2.6 / React 19 / TypeScript 5.9
- PostgreSQL + Drizzle ORM
- Existing storefront, checkout, admin CMS, media, social auth, SEO, payments and workflow foundations
- Existing review schema was present, but no public customer review submission endpoint existed.
- Existing article CMS stored content as plain text/HTML string but admin editing used a basic textarea and did not expose article-level SEO controls.

## Current iteration
Release `1.1.0` adds:
- verified customer product reviews with moderation
- data-driven public product rating/count
- full visual + HTML/source blog editor
- server-side article HTML sanitization
- Blogger-style article SEO fields and metadata integration
- noindex-aware sitemap
- release-contract coverage for the new features

## Validation limitation
Static contracts and TypeScript syntax parsing were executed successfully. Full `npm install`, `npm run typecheck`, `npm run lint`, and `npm run build` could not be completed in the sandbox because dependency installation timed out and the initial archive did not contain a usable `node_modules` tree.
